Site profissional de Rhainara Santos, nutricionista clínica e esportiva.

**SAÚDE | EQUILÍBRIO | RESULTADOS**

O portfólio apresenta sua trajetória, formação acadêmica, experiências profissionais e áreas de atuação, além de facilitar o contato para informações sobre acompanhamento nutricional.

## Funcionalidades

- Layout responsivo para computador, tablet e celular.
- Apresentação profissional e formação acadêmica.
- Experiências organizadas em uma linha do tempo.
- Efeito de destaque nos cartões de experiência.
- Carrossel de áreas de atuação.
- Acesso direto ao WhatsApp, e-mail, Instagram e LinkedIn.
- Navegação do carrossel por setas, teclado e toque.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Como visualizar

Baixe os arquivos do projeto e abra o arquivo `index.html` no navegador.

Mantenha a foto `perfil.jpeg` dentro da pasta `imagens` para que ela apareça corretamente.
